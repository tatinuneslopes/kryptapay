Credenciais de API do Gateway

Conecte a KryptaPay à sua loja virtual, checkout ou SaaS para receber vendas reais via Pix e Cartão com confirmação instantânea.

Exemplo de Integração — POST /api/v1/charges

Envie uma requisição HTTPS autenticada com sua Secret Key no cabeçalho Authorization: Bearer krypta_sec_... e receba QR Code Pix ou aprovação no cartão. 

curl -X POST https://api.kryptapay.com/api/v1/charges \
  -H "Authorization: Bearer krypta_sec_live_SEU_TOKEN_AQUI" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: pedido_10928_xyz" \
  -d '{
    "amount": 97.00,
    "payment_method": "pix",
    "customer": {
      "name": "Comprador Exemplo",
      "email": "cliente@email.com",
      "phone": "+5511999998888"
    }
  }'

Instale o KryptaPay no Celular

Tenha o aplicativo oficial na sua tela inicial com notificações em tempo real.

🍏 No iPhone / Safari:
  1. Toque no botão de Compartilhar (ícone do quadrado com a seta para cima no rodapé).
  2. Role para baixo e selecione "Adicionar à Tela de Início".
  3. Toque em "Adicionar" no canto superior direito.
🤖 No Android / Chrome:
  1. Toque nos três pontinhos (menu) no canto superior direito.
  2. Selecione "Instalar aplicativo" ou "Adicionar à tela inicial".
  3. Confirme a instalação.
