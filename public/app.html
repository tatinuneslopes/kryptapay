Chaves de API do Gateway

Exemplo de Integração — POST /api/v1/charges

Envie uma requisição HTTPS autenticada com sua Secret Key no cabeçalho Authorization: Bearer krypta_sec_... e receba QR Code Pix ou aprovação instantânea. 

curl -X POST https://api.kryptapay.com/api/v1/charges \
  -H "Authorization: Bearer krypta_sec_live_SEU_TOKEN_AQUI" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: pedido_10928_xyz" \
  -d '{
    "amount": 97.00,
    "payment_method": "pix",
    "customer": {
      "name": "Comprador Exemplo",
      "email": "cliente@email.com",
      "phone": "+5511999998888"
    }
  }'
